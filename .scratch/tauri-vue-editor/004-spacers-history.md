# 004 空白占位与撤销重做

**类型：AFK**

## What to build

左侧工具栏提供可拖入画板的空白块。空白块是持久化的布局成员，可被插入、移动
和删除，并参与后续挤占。为所有布局操作增加最多 100 步撤销/重做，同时提供
安全的增删行列能力。

## Acceptance criteria

- [ ] 空白块与未使用格在状态模型和视觉样式上可区分。
- [ ] 插入空白块会向后挤占，溢出时自动扩列。
- [ ] 移动和删除空白块不会改变 PDF 页面集合。
- [ ] 删除含页面的行列前必须阻止操作或先明确迁移内容。
- [ ] 撤销/重做覆盖页面移动、空白、扩列及行列调整。
- [ ] 历史记录上限为 100，打开新文档或工程时正确重置。
