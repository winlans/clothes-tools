# 003 拖拽吸附与插入式重排

**类型：AFK**

## What to build

用户可以拖动任意页面，目标格在拖动过程中高亮，松手后页面必须吸附到格子。
拖到已占用格时按先向下、再向右的顺序执行稳定插入；拖动项原位置自动补齐，
后续页面顺次移动，容量不足时增加最右列。

## Acceptance criteria

- [x] 页面不能停在格子之间，拖动取消后回到原布局。
- [x] 拖到占用格会稳定插入，页码不重复、不丢失。
- [x] 从目标前方或后方拖入时均得到符合列优先顺序的结果。
- [x] 插入溢出时自动扩列，现有行数保持不变。
- [x] 拖动前后成品比例与页面尺寸不变。
- [x] reducer/store 的边界场景和画板拖拽完成自动化测试。

## Verification

- core reducer 测试覆盖向前/向后移动、空格目标、重复页、越界与满容量扩列；
- Pinia store 测试确认移动后页码集合无重复、无丢失；
- Playwright 使用真实 15 页 PDF 将第 1 页拖入第 5 格，得到
  `2,3,4,5,1,6…15`，并验证拖动目标行列；
- 第 15 页拖动中按 Esc 后布局保持不变，拖动前后页面 point 尺寸完全一致。
