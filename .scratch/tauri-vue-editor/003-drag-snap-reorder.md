# 003 拖拽吸附与插入式重排

**类型：AFK**

## What to build

用户可以拖动任意页面，目标格在拖动过程中高亮，松手后页面必须吸附到格子。
拖到已占用格时按先向下、再向右的顺序执行稳定插入；拖动项原位置自动补齐，
后续页面顺次移动，容量不足时增加最右列。

## Acceptance criteria

- [ ] 页面不能停在格子之间，拖动取消后回到原布局。
- [ ] 拖到占用格会稳定插入，页码不重复、不丢失。
- [ ] 从目标前方或后方拖入时均得到符合列优先顺序的结果。
- [ ] 插入溢出时自动扩列，现有行数保持不变。
- [ ] 拖动前后成品比例与页面尺寸不变。
- [ ] reducer/store 的边界场景和画板拖拽完成自动化测试。
