# 017 全屏预览与精确百分比缩放

**类型：AFK**

## What to build

为排版画板增加全屏只读预览。预览复用完整页面和成品裁切两种渲染模式，支持
适合内容、滚轮缩放、平移，以及直接输入任意小数百分比。普通画板也提供相同的
精确缩放控件，避免只能依靠固定倍率的滚轮调整。

## Acceptance criteria

- [x] 画板提供“全屏预览”入口，优先进入系统原生全屏，失败时仍以全窗口遮罩预览。
- [x] 全屏预览是只读画板，不会误触页面、空白块或排版状态。
- [x] 普通画板和全屏预览都能输入 10%–400% 范围内的任意小数百分比。
- [x] 自定义缩放保持视口中心对应的版图位置不跳动。
- [x] 自定义加减按钮支持每次 0.1% 的小数位微调。
- [x] 全屏预览支持适合内容、滚轮缩放、空格键/中键平移和 Esc 退出。

## Verification

- `pnpm --filter @pdf2plt/desktop typecheck`
- `pnpm --filter @pdf2plt/desktop test`
- `pnpm --filter @pdf2plt/desktop build`
- 浏览器烟测全屏打开/退出、`37.125%` 输入和 `0.1%` 微调。
