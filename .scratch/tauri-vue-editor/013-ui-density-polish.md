# 013 压缩文档栏并统一布局控件

**类型：AFK**

## What to build

减少编辑器顶部的无效纵向占用：把当前 PDF 的文件名、页数和单页尺寸合并到
顶栏，并移除独占整行的文档摘要。将“每列页数”改为自定义减号、数值输入和
加号组成的步进器，隐藏浏览器原生数值按钮，但保留键盘输入能力。空白占位在
页面侧栏和画板中统一使用白色底色，便于直接辨认最终拼版中的空白页面。产品
流程收敛为“导入 PDF、排版微调、导出 SVG”，不再显示工程文件的打开和保存
入口。

## Acceptance criteria

- [x] 当前 PDF 信息与应用名称、操作按钮位于同一顶栏，大窗口不再单独占一行。
- [x] 文件名过长时截断显示，不挤压右侧操作按钮；窄窗口允许文档信息换行。
- [x] “每列页数”使用自定义减号和加号按钮，点击后立即重新自动排版。
- [x] 数值仍可手动输入，且原生浏览器微调按钮不再显示。
- [x] 每列页数不允许通过减号降低到 1 以下。
- [x] 侧栏空白块与画板空白占位默认均为白色背景。
- [x] 顶栏不再显示“打开工程”和“保存工程”，普通转换流程不依赖工程文件。

## Verification

- App 组件测试验证文档摘要被移除，紧凑顶栏显示页数和页面尺寸。
- LayoutEditor 组件测试验证自定义加减按钮与自动排版状态同步。
- 真实 PDF 浏览器回归验证紧凑顶栏、自定义步进器和侧栏白色空白块。
- `pnpm test`
- `pnpm typecheck`
- `pnpm build`
