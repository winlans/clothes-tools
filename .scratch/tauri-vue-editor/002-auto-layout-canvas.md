# 002 自动排版并显示 Vue 画板

**类型：AFK**

## What to build

导入 PDF 后让用户填写每列页数，默认 3。共享核心生成列优先二维布局，Vue +
Konva 画板按 PDF point 坐标显示裁切前页面预览，并支持光标中心缩放、平移和
适合内容。缩放只能改变视图，不得改变输出尺寸。

## Acceptance criteria

- [ ] 每列页数必须为正整数，列数由页数自动计算。
- [ ] 15 页、每列 3 页生成 5 列 × 3 行，页码为 `1,2,3 | 4,5,6 ...`。
- [ ] 页面预览、页码标签和格子边界在画板中正确对齐。
- [ ] 滚轮缩放范围为 10%–400%，空格键/中键平移可用。
- [ ] “适合内容”能将有效网格完整放入可视区域。
- [ ] 布局核心和 Vue 画板行为均有自动化测试。
