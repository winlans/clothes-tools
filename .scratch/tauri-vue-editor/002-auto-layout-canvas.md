# 002 自动排版并显示 Vue 画板

**类型：AFK**

## What to build

导入 PDF 后让用户填写每列页数，默认 3。共享核心生成列优先二维布局，Vue +
Konva 画板按 PDF point 坐标显示裁切前页面预览，并支持光标中心缩放、平移和
适合内容。缩放只能改变视图，不得改变输出尺寸。

## Acceptance criteria

- [x] 每列页数必须为正整数，列数由页数自动计算。
- [x] 15 页、每列 3 页生成 5 列 × 3 行，页码为 `1,2,3 | 4,5,6 ...`。
- [x] 页面预览、页码标签和格子边界在画板中正确对齐。
- [x] 滚轮缩放范围为 10%–400%，空格键/中键平移可用。
- [x] “适合内容”能将有效网格完整放入可视区域。
- [x] 布局核心和 Vue 画板行为均有自动化测试。

## Verification

- core 自动布局测试覆盖 15 页 `5 × 3`、尾列空格和非法每列页数；
- desktop 测试覆盖相机适配、10%–400% 缩放、光标中心缩放、平移和 Vue
  自动排列表单；
- Playwright 导入真实 15 页 PDF，确认画板生成、15 张缩略图、`5 × 3`
  布局、滚轮缩放、空格键拖拽平移与“适合内容”，页面异常为 0；
- 诊断并修复 MuPDF WASM 在 Vite 中的哈希资源 URL，浏览器回归脚本保留在
  `browser-layout-smoke.cjs`。
