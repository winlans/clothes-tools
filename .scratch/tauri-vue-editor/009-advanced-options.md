# 009 高级接缝和导出选项

**类型：AFK**

## What to build

在右侧检查器中公开自动、手动和无接缝模式、四条接缝、四个外边界、红线阈值、
保留辅助线/背景和允许未使用页。所有设置即时校验，桌面端、工程文件和 CLI
使用同一模型。

## Acceptance criteria

- [ ] 自动、手动、无接缝三种模式切换后预览与导出一致。
- [ ] 裁切范围必须位于页面内且起点小于终点。
- [ ] 修改参数后成品毫米尺寸实时更新。
- [ ] 默认阻止存在未使用页面的导出，显式允许后才能继续。
- [ ] 工程保存、桌面导出和 CLI 对全部设置解释一致。
- [ ] 639 PDF 的外边界覆盖用例通过回归测试。
