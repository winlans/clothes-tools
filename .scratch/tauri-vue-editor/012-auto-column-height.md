# 012 从逐页红线自动识别每列页数

**类型：AFK**

## What to build

复用红线检测阶段的逐页方向样本识别列优先 PDF 的每列页数。首列页面应连续
存在右拼接线且不存在左拼接线；首列末页存在上拼接线且不存在下拼接线；紧随
其后的页面首次出现左拼接线。只有这些信号一致时才应用识别结果。

## Acceptance criteria

- [x] 核心层可从逐页左、右、上、下红线签名推断每列页数。
- [x] 红线缺失或边界信号矛盾时不返回推断值。
- [x] 新导入且尚未编辑的布局自动采用推断值，不产生撤销历史。
- [x] 用户修改每列页数、拖拽页面或插入空白后，迟到的检测结果不得覆盖布局。
- [x] 工程文件重开保持已保存布局，不受重新检测影响。
- [x] 工具栏显示“红线识别：每列 N 页”，数值输入仍可人工调整。

## Verification

- core 单元测试覆盖 3 行序列以及缺少左线、末页仍有下线等拒绝场景。
- desktop store/App 测试覆盖自动应用和保护用户修改。
- 528 真实 PDF 浏览器回归识别为每列 3 页、`5 × 3`。
- 639 真实 PDF 浏览器回归识别为每列 4 页、`2 × 4`。
- `pnpm test`
- `pnpm typecheck`
- `pnpm build`
