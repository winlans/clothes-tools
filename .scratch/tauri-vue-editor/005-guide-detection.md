# 005 自动红线检测与裁切预览

**类型：AFK**

## What to build

把现有红色像素筛选、行列计数和跨页聚类算法迁移到共享 TypeScript 核心。
导入完成后自动检测左右和上下接缝，并让画板切换显示完整页面或按当前接缝裁切
后的拼接预览。检测失败时提供手动填写入口。

## Acceptance criteria

- [ ] 默认红色阈值和最小跨度与旧 CLI 一致。
- [ ] 检测工作在 MuPDF Worker 中，不复制不必要的大像素缓冲区。
- [ ] 输出每条检测线的 point 坐标和检测来源。
- [ ] 裁切预览与当前布局同步，切换模式不改变布局页码。
- [ ] 无红线或只有部分红线时指出缺失方向及可用修复方式。
- [ ] 两份真实 PDF 的检测结果落在旧工具结果 `±1pt` 内。
